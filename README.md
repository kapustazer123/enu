# +90% — портал подготовки к сессии

Единое место для подготовки к экзаменам по всем предметам:

- **📖 Материалы** — конспекты тем в Markdown, с формулами (LaTeX через KaTeX) и таблицами;
- **✅ Квизы** — тесты четырёх типов (один ответ, несколько ответов, верно/неверно, ввод ответа) с пояснениями, разбором ошибок и режимом «повторить ошибки»;
- **🃏 Карточки** — термины и формулы для запоминания, режим «только невыученные»;
- **🎓 Вопросы к экзамену** — список билетов с ответами, отметками «знаю / повторить / не знаю» и случайным билетом;
- **🗓 Занятия** — недельное расписание пар с числителем/знаменателем, «идёт сейчас» и парами на сегодня на главной;
- **📅 Сессия** — все экзамены и консультации с обратным отсчётом;
- **🔍 Поиск** по всем материалам.

- **Аккаунты:** вход по логину и паролю, прогресс синхронизируется между устройствами; **заметки к билетам**; **статистика ошибок** и квиз «Мои слабые места»; **рейтинг** по группам.

Без входа всё работает, прогресс хранится в браузере; при первом входе он переносится в аккаунт. Сборка не нужна: фронтенд — чистый JS, бэкенд — Cloudflare Worker (`worker/`) с базой D1.

## Запуск локально

Только контент (без аккаунтов):

```bash
python3 -m http.server 8000
```

С аккаунтами и локальной базой D1:

```bash
npx wrangler dev
```

Откройте адрес, который покажет команда (обычно http://localhost:8787).

## Публикация

Сайт публикует **Cloudflare Pages**: он подключён к репозиторию и обновляется после каждого пуша в `main`. Сборка не нужна (Build command — пусто, Output directory — `/`).

GitHub Actions при каждом пуше запускает `scripts/validate.mjs` — если в контенте ошибка, коммит будет с красным крестиком.

## Бэкенд

- `worker/index.js` — API: `/api/register`, `/api/login`, `/api/logout`, `/api/me`, `/api/password`, `/api/progress`, `/api/leaderboard`.
- `worker/schema.js` — таблицы D1; создаются автоматически при первом запросе.
- `wrangler.jsonc` — конфигурация Worker. База `enu-db` создаётся при первом деплое автоматически.
- Пароли — PBKDF2-SHA256 (100 000 итераций) с солью; сессия — httpOnly-cookie на 60 дней; после 10 неверных паролей вход блокируется на 15 минут.
- Прогресс отправляется операциями (`topic`, `quiz`, `card`, `question`, `note`, `answer`, `reset`, `import`) — два устройства не затирают изменения друг друга.
- Администраторы — логины из переменной `ADMIN_USERNAMES` в `wrangler.jsonc` (через запятую), права выдаются при регистрации.
- **Админка** (`#/admin`): правка файлов `content/**.json|md` прямо на сайте — Worker делает коммит в репозиторий, Cloudflare пересобирает сайт. Нужен секрет `GITHUB_TOKEN` в настройках Worker (fine-grained токен GitHub с доступом Contents: Read and write только к этому репозиторию). Там же — сброс пароля студенту.
- **Ссылки на онлайн-занятия** — публичные: поле `link` (и `platform`) у пары в `content/timetable.json`, кнопка «подключиться» видна всем. Если понадобится их закрыть — уберите `link` из файла и загрузите ссылки в админке: тогда их увидят только студенты, введшие **код группы** в аккаунте.

## Структура

```
content/
├── subjects.json              ← список предметов (порядок = порядок на главной)
├── timetable.json             ← расписание занятий
├── _template/                 ← шаблон нового предмета — копируйте его
└── <id-предмета>/
    ├── subject.json           ← название, дата экзамена, список тем и квизов
    ├── topics/*.md            ← конспекты
    ├── quizzes/*.json         ← квизы
    ├── flashcards.json        ← карточки
    └── questions.json         ← вопросы к экзамену
assets/                        ← код портала (для контента трогать не нужно)
scripts/validate.mjs           ← проверка контента
```

## Как добавить предмет

1. Скопируйте `content/_template` в `content/<id>` (id — латиницей, например `history`).
2. Заполните `subject.json`.
3. Добавьте id в `content/subjects.json`.
4. Проверьте: `node scripts/validate.mjs`.

### subject.json

```json
{
  "title": "История России",
  "color": "#e0742b",
  "teacher": "Петрова А. В.",
  "description": "Краткое описание, *markdown* можно",
  "exam": { "type": "Экзамен", "date": "2027-01-20T10:00", "place": "ауд. 214" },
  "events": [{ "type": "Консультация", "date": "2027-01-19T14:00", "place": "ауд. 214" }],
  "topics": [
    { "id": "rus-1", "title": "Древняя Русь", "summary": "IX–XII вв.", "file": "topics/01-ancient-rus.md" }
  ],
  "quizzes": [
    { "id": "dates", "title": "Даты", "topic": "rus-1", "file": "quizzes/dates.json" }
  ],
  "flashcards": "flashcards.json",
  "questions": "questions.json",
  "links": [{ "title": "Учебник", "url": "https://…" }]
}
```

`type` у экзамена — любой текст: «Экзамен», «Зачёт», «Дифзачёт», «Курсовая».

Даты экзаменов и консультаций из `exam` и `events` автоматически попадают в раздел «Сессия».

### Расписание занятий (`content/timetable.json`)

```json
{
  "group": "ИС-21",
  "semesterStart": "2026-09-01",
  "semesterEnd": "2026-12-27",
  "firstWeek": "числитель",
  "lessons": [
    { "day": 1, "start": "08:00", "end": "08:50", "subject": "history", "type": "Лекция", "room": "214", "teacher": "Петрова А. В." },
    { "day": "чт", "start": "10:00", "end": "10:50", "title": "Физкультура", "type": "Практика", "week": "знаменатель" },
    { "day": 5, "start": "14:00", "end": "14:50", "subject": "history", "type": "СРСП", "link": "https://zoom.us/…" }
  ]
}
```

- `day` — 1–7 (1 = понедельник) или `пн`, `вт`, …
- `subject` — id предмета из `subjects.json` (тогда пара ведёт на страницу предмета); для предметов без материалов пишите `title`.
- `week` — `числитель` / `знаменатель`; без него пара идёт каждую неделю. Первая неделя от `semesterStart` — это `firstWeek`.
- После `semesterEnd` пары не показываются, а на главной написано «Сессия».

### Квиз (`quizzes/*.json`)

```json
{
  "title": "Название",
  "shuffle": true,
  "questions": [
    { "type": "single",    "q": "Вопрос?", "options": ["A", "B", "C"], "answer": 1, "explain": "Почему B" },
    { "type": "multiple",  "q": "Выберите все…", "options": ["A", "B", "C"], "answer": [0, 2] },
    { "type": "truefalse", "q": "Утверждение.", "answer": true },
    { "type": "text",      "q": "Сколько будет 2+2?", "answer": ["4", "четыре"] }
  ]
}
```

- Номера вариантов в `answer` считаются **с нуля**. Варианты перемешиваются автоматически (отключить: `"shuffleOptions": false`).
- Ответ типа `text` сравнивается без учёта регистра, пробелов по краям, «ё/е» и «,/.».
- `type` можно не писать — он определится по `answer`.
- Во всех текстах работает Markdown и формулы: `$x^2$`, `$$\int f(x)\,dx$$`. В JSON обратный слэш удваивается: `"$\\frac{1}{2}$"`.

### Карточки (`flashcards.json`)

```json
[{ "front": "Термин", "back": "Определение" }]
```

### Вопросы к экзамену (`questions.json`)

```json
[{ "q": "Текст билета", "topic": "rus-1", "a": "Ответ в **markdown** (необязательно)" }]
```

Номер вопроса — его позиция в списке; можно задать свой: `"id": "12"`.
