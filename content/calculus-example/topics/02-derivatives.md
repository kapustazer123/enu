# Производная

## Определение

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

Геометрический смысл: $f'(x_0)$ — угловой коэффициент касательной к графику в точке $x_0$.

## Таблица производных

| Функция | Производная |
|---------|-------------|
| $C$ | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |

## Правила дифференцирования

1. $(u \pm v)' = u' \pm v'$
2. $(uv)' = u'v + uv'$
3. $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
4. $\big(f(g(x))\big)' = f'(g(x)) \cdot g'(x)$ — производная сложной функции
